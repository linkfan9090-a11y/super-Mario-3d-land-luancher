# Mario Land Mod Launcher

A fan-made Nintendo 3DS homebrew profile selector prototype for a future Super Mario 3D Land mod manager.

Current features

- Four selectable demo profiles
- UP and DOWN buttons to change profiles
- A button to save the selected profile
- Saves the selection to "sdmc:/3ds/MarioLandMods/selected.txt"
- START button to exit

Important

This is an early prototype. Selecting a profile does not currently install mods, patch game files, or launch Super Mario 3D Land.

Build

GitHub Actions builds the project using the devkitPro devkitARM environment.
